# Pagewise GEO QA fixture

This public repository hosts a synthetic website used only for bounded
Pagewise early-prototype quality assurance. It contains no customer data.

- `index.html` is the currently published fixture.
- `version-a.html` is the baseline.
- `version-b.html` is the user-updated comparison version.

The same public root URL is retained while `index.html` moves once from A to B
during an authorized QA cycle.
